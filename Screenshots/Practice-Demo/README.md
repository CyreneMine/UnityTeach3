## 展示建议

- 项目封面用 01；玩法介绍优先用 09、12 或 13；操作反馈用 14；闭环结果用 15。
- 11 适合作为实现与待完善边界的说明图，不优先作为作品封面。
- 截图证明其中可见的状态，不能单独证明所有角色/塔组合、音频效果、冷启动存档或性能指标均通过验证。
- 本次 Agent 使用已有存档运行；08 说明同一进程内的奖励回流，不替代关闭程序后重新读取存档的测试。
