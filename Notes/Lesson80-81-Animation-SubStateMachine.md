# 第 80–81 课：动画子状态机

## 学习目标

- 理解 Animator 子状态机用于整理一组相关动画状态。
- 验证主状态机进入子状态机、播放其中状态并返回主状态机的流程。

## 独立实现

- 在上一课的 `Lesson53.controller` 中新增 `New StateMachine`。
- 子状态机以 `HumanoidIdleJumpUp` 为默认状态。
- 主状态机中的 Blend Tree 通过 `New Trigger` 进入子状态机。
- 跳跃动画播放到 Exit Time 后返回主状态机。

## 验证方式

- 在 Play Mode 中通过 Animator 参数面板手动触发 `New Trigger`，观察状态进入子状态机并在动画结束后返回。
- 题目文字使用 K 键触发；本次练习主动省略键盘监听，因为按键代码已经掌握，本课重点是验证子状态机结构和状态流。

## 复查结论

- 子状态机已真实挂入 Base Layer，而不是孤立资源。
- 进入条件、子状态机默认状态和返回过渡均已配置。
- 手动 Trigger 验证可以覆盖本课需要理解的 Animator 状态流。
