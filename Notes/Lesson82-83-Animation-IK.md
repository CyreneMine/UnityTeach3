# 第 82–83 课：动画 IK 控制

## 学习目标

- 理解 Animator IK Pass 与 `OnAnimatorIK` 的调用关系。
- 使用 LookAt IK 让角色身体和头部随鼠标输入发生部分旋转。

## 独立实现

- 在 Base Layer 开启 IK Pass。
- 在 `OnAnimatorIK` 中调用 `SetLookAtWeight` 和 `SetLookAtPosition`。
- 累加 Mouse X、Mouse Y 输入，并把角度限制在 `-30` 到 `30` 度。
- 通过场景中的头部目标 Transform 提供 LookAt 计算起点。

## 调试与修正

- 初版代码分别计算水平和垂直旋转结果，再用 `+=` 相加。在零旋转时，两份相同的世界位置也会相加，造成位置和距离翻倍。
- 随后改为教程写法：第一次计算水平旋转结果，第二次以 `=` 对该结果继续施加垂直旋转，消除了重复相加问题。

## 坐标空间边界

- `Quaternion * Vector3` 只执行向量旋转，不知道这个 `Vector3` 表示世界坐标点还是方向。
- `Vector3.up`、`Vector3.right` 表示固定的世界轴方向；`transform.up`、`transform.right` 表示会随角色旋转而改变的自身轴方向。角色发生平移不会改变自身轴，角色发生旋转才会改变。
- 当角色已经转向时，世界的左、右不一定仍对应角色头部的左、右；需要让 LookAt 控制相对角色朝向工作时，应使用角色自身轴。
- 轴方向回答“朝哪个方向旋转”，旋转中心回答“围绕哪里旋转”，两者是独立概念。使用自身轴不会自动改变旋转中心。
- 教程将 `target.position + forward * distance` 这个世界坐标点直接旋转，因此实际旋转中心是世界原点。
- 当角色位于世界原点附近时，演示效果通常正常；角色远离原点后，目标点可能随角色位置产生额外偏移。
- 更通用的做法是只旋转从头部指向前方的方向向量，最后再把旋转后的方向加回头部世界坐标。本课按教程方案保留，并记录这一适用边界。

## 验证结果

- Animator 的 IK Pass 已开启。
- LookAt 目标引用完整，当前脚本组件已启用。
- 当前实现使用 `transform.up` 和 `transform.right` 作为旋转轴，并反转 Mouse Y 输入，使鼠标向上对应抬头。
