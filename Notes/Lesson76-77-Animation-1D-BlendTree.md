# 第 76–77 课：动画 1D 混合

## 学习目标

- 理解 Animator 1D Blend Tree 如何根据一个浮点参数混合多个动画。
- 使用键盘输入驱动待机、前后行走和前后奔跑。

## 独立实现

- 新建独立的 `Lesson52.controller`，避免破坏上一课包含跳跃、转向、动画分层和遮罩的 Controller。
- 使用 `Speed` 作为 1D 混合参数，设置五个阈值：
  - `-1`：跑步动画倒放，表现为向后跑。
  - `-0.5`：走路动画倒放，表现为向后走。
  - `0`：待机。
  - `0.5`：向前走。
  - `1`：向前跑。
- `Lesson52.cs` 使用垂直输入控制正负方向，默认倍率为 `0.5`；按住左 Shift 时切换到倍率 `1`，松开后恢复行走倍率。

## 调试与修正

- 初次复查时，场景切换到新 Controller 后仍运行上一课的 `Lesson50` 脚本。旧脚本持续写入新 Controller 不存在的 `horizontalOffset`，导致 Console 每帧报参数不存在。
- 后续为本课建立独立脚本并禁用旧组件，使脚本写入的参数与 Controller 参数保持一致。

## 验证结果

- 场景中的 Ethan 已引用 `Lesson52.controller`，并启用 `Lesson52` 组件。
- Blend Tree 是 Base Layer 的默认状态，`Speed` 可覆盖 `-1` 到 `1` 的五档动作。
- 最近一次 Play Mode 日志未再出现 Animator 参数不存在、空引用或编译错误。

## 边界

- 当前后退效果通过正向 Walk、Run 动画倒放实现，适合本课验证；真实项目有专用后退动画时应使用对应 Clip。
- Shift 状态在设置本帧 `Speed` 后更新，因此切换会晚一帧，肉眼通常不可见；后续可直接根据按键状态计算倍率，使代码意图更直接。
