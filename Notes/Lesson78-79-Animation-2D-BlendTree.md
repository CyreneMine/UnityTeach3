# 第 78–79 课：动画 2D 混合

## 学习目标

- 理解 2D Blend Tree 使用两个浮点参数在多个方向动画之间混合的方式。
- 使用键盘输入表现待机、前进、后退、左转和右转。

## 独立实现

- 新建独立的 `Lesson53.controller`，使用 2D Freeform Directional 混合类型。
- 使用 `Horizontal` 作为横轴参数，使用 `Vertical` 作为纵轴参数。
- 动画点位设置如下：
  - `(0, 0)`：待机。
  - `(0, 1)`：向前跑。
  - `(0, -1)`：向前跑动画倒放，表现为后退。
  - `(-1, 0)`：向左转。
  - `(1, 0)`：向右转。
- `Lesson53.cs` 将水平和垂直输入持续写入对应的 Animator 参数。

## 调试过程

- 初次配置曾使用 `x`、`y` 作为混合参数，但 Controller 中不存在同名参数，因此 Unity 报 Blend Tree 参数不存在。
- 后续将混合参数统一为 Controller 和脚本中实际存在的 `Horizontal`、`Vertical`，错误不再出现。
- 上一课的 `Lesson52` 和更早的 `Lesson50` 组件均已禁用，仅启用当前练习脚本，避免多个脚本同时控制 Animator。

## 验证结果

- `Lesson53.controller` 已绑定到场景中的 Ethan，并作为 Base Layer 的默认状态运行。
- 左侧动画引用 `HumanoidRunLeft`，右侧引用 `HumanoidRunRight`，方向与坐标一致。
- 最近一次 Controller 导入后未发现参数不存在、空引用或编译错误。

## 边界

- 当前后退使用正向跑步动画倒放，适合验证混合树；真实项目可换成专用后退动画。
- 该练习主要验证动画混合。角色真实位移和朝向控制仍应由后续角色控制逻辑负责。
