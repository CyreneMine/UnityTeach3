# 第 16–17 课：Sprite Mask 练习复盘

## 完成情况

- 状态：已完成。
- 复查日期：2026-09-12。
- 第 16P：学习 Sprite Mask，并开始制作类似放大镜的遮罩效果。
- 第 17P：独立完成练习并复查场景配置。

## 自主实现

- 使用普通尺寸的角色 Sprite 作为遮罩外的基础画面。
- 复制同一角色 Sprite，将 Transform Scale 设置为 2，作为镜片内显示的放大画面。
- 将放大角色的 SpriteRenderer Mask Interaction 设置为 `Visible Inside Mask`。
- 使用圆形 Sprite Mask 限制放大角色的可见区域。
- 使用放大镜图片表现镜框，并把 Sprite Mask 设为放大镜对象的子对象，使二者可以一起移动。

## 复查与验证

- 普通角色、放大角色、放大镜和 Sprite Mask 均已启用，Sprite 引用有效。
- 普通角色不参与遮罩；放大角色只在 Sprite Mask 内可见。
- 放大角色使用相同 Sprite 并放大到 2 倍，符合镜片内显示放大画面的目标。
- 放大镜的渲染顺序高于角色，可以把镜框显示在内容上方。
- 用户在 Scene 视图中直接拖动放大镜，确认遮罩经过角色时能够看到放大效果。

## 验证方式说明

- 本练习的核心是理解 Sprite Mask 与 SpriteRenderer 的关系，因此在 Scene 视图中手动拖动放大镜即可完成验证。
- 如果改为 Game 视图交互，可以再用脚本读取鼠标世界坐标并控制放大镜对象的位置；这只改变移动输入方式，不改变当前遮罩结构。
- 当前保存位置不必持续与角色重叠，复查依据是拖动过程中的实际遮罩效果。

## 已知边界

- 当前没有运行时鼠标控制，因此进入 Game 视图后放大镜不会自动跟随鼠标。
- 练习使用的教程素材位于已忽略的 `Standard Assets` 中，不提交到仓库；其他设备拉取仓库后需要自行准备对应资源。
